  to the server" are permission to commit/push. I fixed this by updating

- **Missing transcript metadata.** The first `HANDOFF.md` entries did not record
  timestamps or the AI model used. The operator asked for these, so I backfilled
  approximate timings and added an AI annotation for every response.
- **Sonnet 5 attribution note.** The operator stated Sonnet 5 was used to create
  the plan. In this session the plan was actually generated by SWE-1.7 Medium
  (Devin). I kept the operator's statement as a note in `HANDOFF.md` while

## What was rejected and why

- **Per-serial locking for R5.** A global `threading.Lock` was chosen for the
  60-minute build to guarantee no lost writes. Per-serial locks were dropped
  from the timebox as a post-timebox refinement.
- **Docker / docker compose.** Not needed to satisfy AC1–AC8 and would consume
  time better spent on correctness and tests; listed as post-timebox.
- **Real paginated search endpoint.** The scale question is answered in design in
  `README.md`; a real implementation with volume measurement is post-timebox.
- **Complex React build toolchain.** Used React from CDN with `createElement`
  instead of `create-react-app`/Vite to keep the app runnable with no build
  step and satisfy "starts in at most two commands."
